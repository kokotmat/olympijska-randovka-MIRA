# Aktualizace bez otevření prodeje nebo brány

Tento zdroj v GitHubu sám neaktualizuje Google Apps Script. Cloudflare nasazuje pouze veřejný web a gateway. Původní širší rozpracovaná větev rezervací zůstává oddělená.

1. `node backend/production/build.mjs` vytvoří kompletní `Randovka_PRODUKCE.gs` s lokálním generátorem QR. Celý obsah patří do hlavního souboru existujícího Apps Script projektu. Nejprve si uložte současný zdroj a číslo nasazené verze pro návrat.
2. Přidejte **stejný nový náhodný interní klíč** `SCANNER_GATEWAY_SECRET` (alespoň 32 znaků, doporučeno 64 náhodných znaků) v Cloudflare Pages → projekt webu → Settings → Variables and Secrets → Production → typ Secret, a v Apps Script → Project Settings → Script Properties. Nezadávejte jej do repozitáře ani chatu. Neměňte PIN, SESSION_SECRET, Fio token nebo nastavení otevření prodeje/brány.
3. Nejdříve nasaďte Cloudflare gateway s klíčem. Při přechodu na protokol v2 starší backend přihlášení odmítne; aktualizace obou částí proto proveďte v jednom servisním okně při zavřené bráně. Potom aktualizujte Apps Script **existující nasazení** na novou verzi, aby URL zůstala stejná. Nový backend odmítá nepodepsané přihlášení, vyžaduje důvěryhodnou gateway. Vložit pouze gateway bez aktualizace backendu neopraví globální blokování!
4. Používejte skener na `https://olympijskarandovka.cz/kontrola-vstupenek.html`. Původní Apps Script odkaz zobrazí odkaz na tento skener. Podepsaná relace nadále platí šest hodin; bránu ověřuje každý scan na serveru.
5. Ověřte přihlášení a **zavřenou bránu**. Skutečné zatížení tabulky a e-mailovou frontu testujte až v samostatné kopii projektu a tabulky, s testovacími příjemci a bankovním adaptérem. Nepřepínejte ostrý projekt kvůli testům do jiného režimu.

Podepsaný protokol skeneru v2 omezuje jedno zařízení na 10 chybných pokusů / 5 minut. Zařízení ve stejné síti mají samostatné limity a vyšší společný limit 100 chybných pokusů / 5 minut proti střídání identifikátorů. Další pokusy již zablokovaného zařízení nezvyšují společný čítač. IP ani identifikátor zařízení nejsou předávány Googlu: gateway předává oddělené HMAC otisky a podpis pokrývá také síť. Přímý nepodepsaný požadavek je odmítnut. Nejde o síťový DDoS filtr. Cloudflare gateway, klient skeneru i Apps Script musí používat stejnou verzi protokolu.

`setupOperationsDashboard()` spustí vlastník jednou z editoru. Vytvoří samostatnou neveřejnou Google tabulku a uloží její ID do `OPS_SPREADSHEET_ID`; odkaz vypíše do protokolu. Nastavení sdílení původní rezervační tabulky se nemění. Přehled se potom obnovuje v `maintenance_()`; ručně jej obnoví `refreshOperationsDashboard()`. Čtení přehledu nezavolá banku ani neodešle e-mail. Zobrazuje režim, prodej/bránu, kontrolu konfigurace a kapacity, poslední ověření banky, zbývající adresáty, čekající/připravované/nejisté/chybné e-maily, pozdní platby a stav automatiky. Datum aktualizace musí být čerstvé, jinak jde o starý snímek. Základní barevné stavy mají také slovní označení.

`operationsHealth()` je dostupné pouze vlastníkovi z editoru. Nevrací osobní údaje ani tajné hodnoty a nemá veřejnou HTTP cestu. Stáří čekajících zpráv je od poslední změny stavu objednávky, u ručně znovu zařazených zpráv orientační; nejde o historický monitoring ani potvrzení doručení do schránky. Kvóta patří spouštějícímu účtu a mohou ji sdílet další skripty. Zachycená chyba údržby obsahuje pouze pevný kód, nikoli syrovou odpověď banky.

Webový výběr stolů používá `GET /api/tables`, pouze čtení existujících `capabilities` a `getTables`. Gateway má pevný backend a sdílenou interní cache 15 s; klient nebere snímek starší 60 s. Při otevřeném dialogu obnovuje po 30 s, pouze na viditelné kartě. Při zavřeném prodeji nebo testovacím režimu se zobrazí označená ukázka bez tvrzení o dostupnosti. Živá čísla a filtrování podle počtu platí až pro otevřený live režim. Výběr sám nezapisuje rezervaci: kapacitu musí při dokončení znovu ověřit `reserve_()` pod zámkem. `reservationAdapter` na veřejném webu nadále zůstává null; tento commit nezapíná prodej ani bránu.

`node tests/production-system.mjs` testuje skutečné funkce proti izolovaným paměťovým náhradám Google API. Není to měření latence Google, skutečná souběžnost více procesů ani důkaz doručitelnosti e-mailů. Automatizované testy nikdy nepoužívají živé tokeny, tabulku ani banku.

Rollback: nejprve vraťte předchozí Apps Script verzi existujícího nasazení, poté odpovídající Git commit/Cloudflare deployment. Klíč může zůstat nastavený; starší backend nadbytečné podepsané pole ignoruje.
